# CE463 — Digital Signal and Image Processing

Python implementations of basic digital image processing concepts, including grayscale image manipulation, image sampling, and image quantization.

## Examples

- **Grayscale Images:** Load, display, and invert a grayscale image.
- **Image Sampling:** Downsample an image to demonstrate the effect of reduced resolution.
- **Image Quantization:** Compare images represented at different bit depths.

## Technologies

- Python
- NumPy
- Matplotlib
- Pillow
- scikit-image
- Jupyter Notebook

## Getting Started

Install the required libraries:

```bash
pip install numpy matplotlib pillow scikit-image notebook
```

Open the notebook in Jupyter and run the cells in order.

## Project Structure

- `SRI.41.008.010.23_Assignment1.ipynb` — Main notebook containing the examples.
- `sample_image.jpg` — Sample image used in the grayscale example.
