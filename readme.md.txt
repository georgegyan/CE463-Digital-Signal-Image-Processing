## Environment Information

- **Environment name:** `image_proc_env`
- **Python version:** 3.10.22
- **Libraries:** NumPy, Matplotlib, Pillow, scikit-image

## Assignment Examples

This notebook reproduces three Python examples from the reference material:

1. Grayscale image display and intensity inversion.
2. Image sampling and downsampling.
3. Image quantization at different bit depths.

## How to Reproduce

1. Install Anaconda or Miniconda.
2. Activate the `image_proc_env` environment.
3. Install the required libraries if they are not already installed.
4. Open Jupyter Notebook or JupyterLab.
5. Open `StudentID_Assignment1.ipynb`, replacing `StudentID` with your actual student ID.
6. Ensure the `image_proc_env` kernel is selected.
7. Place `sample_image.jpg` in the same folder as the notebook.
8. Restart the kernel and run all cells from top to bottom.
